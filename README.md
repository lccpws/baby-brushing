# 宝宝刷牙小游戏
**日期**：2026-07-21（更新：2026-07-28）
---

## 需求背景

两岁宝宝不爱刷牙。借鉴"假 B 超虫虫"哄娃思路，做刷牙激励页面：
虫虫画得像真虫子（有分节身体 + 大圆眼睛 + 触角），让宝宝畏惧从而乖乖刷牙。

---

## 核心功能

### 虫虫位置随机

- 每次点"开始刷牙"，从 15 个候选位置中 Fisher-Yates 洗牌，随机取 8 个
- 位置分布在上下排牙齿之间 + 舌头区域，覆盖整个口腔
- 口腔和牙齿完全固定，只有虫虫自己扭动

### 每日不同虫虫主题（共 7 种，自动轮换）

| 星期 | 虫虫         | 配色 |
| ---- | ------------ | ---- |
| 周一 | 🐛 粉粉小肉虫 | 粉红 |
| 周二 | 🐛 绿色菜青虫 | 草绿 |
| 周三 | 🐛 蓝色水虫   | 天蓝 |
| 周四 | 🐛 紫色蛞蝓   | 紫色 |
| 周五 | 🐛 橙色毛毛虫 | 橙色 |
| 周六 | 🐛 红色小红虫 | 红色 |
| 周日 | 🐛 灰色土虫   | 灰色 |

### 虫虫形象设计

- SVG 手绘：5 节分节身体（头宽尾细）+ 大圆眼睛（白底黑瞳，有高光点）+ 触角天线 + 嘴巴
- 纯 SVG，无 emoji，保证所有设备渲染一致
- 身体不同部位颜色深浅不一，有质感
- 虫虫左右轻微摇摆动画（相位错开，不同步）

### 倒计时逻辑

- 2 分钟（120 秒），8 只虫虫，每 15 秒消失 1 只
- 进度条实时显示 + 大字倒计时
- 刷完全部：撒彩带 + 完成卡片

### 家长控制

- 右上角"↺ 重来"可随时重置
- 🔊/🔇 一键静音（Web Audio 合成音，无需音频文件）

---

## 技术实现要点

- 口腔 SVG + 虫虫层分离：口腔用 `viewBox` 固定，虫虫绝对定位在 `.mouth-stage` 上方
- 虫虫 SVG `viewBox="0 0 60 32"`，用舞台百分比定位，`transform: translate(-50%,-50%)` 居中对齐
- `worm.gone` 类触发动画：`scale(0) rotate(260deg)` + `opacity:0`
- 每日主题按"一年中第几天"取模，同一天刷新页面主题不变

---

## 用法

直接用浏览器打开 HTML 文件即可。开始屏显示"今日虫虫：XXX"，点击开始，虫虫随机分布、2 分钟倒计时。
